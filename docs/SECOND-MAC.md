# Второй Mac: рабочие боты

На втором Mac бот работает «по-настоящему» (gb2, GE1, GE3 и другие аккаунты). Трогать его — только когда пользователь
просит прямо; запущенные аккаунты не останавливать без явной просьбы; ничего не удалять — переименовывать
(`app.prev-<время>`, `*.bak`).

## Доступ и раскладка
- `ssh -i ~/.ssh/id_ed25519 invoker@<адрес в локальной сети>` (адрес меняется с сетью: 2026-11-16 был `192.168.0.111`, потом `192.168.31.24`; искать: `dns-sd -B _ssh._tcp local.` — «MacBook Air», или вход по ключу на адреса из `arp -a`).
- `~/orbit/app` — сборка (`distZip`, распакованная), `~/orbit/start.command` — запуск (JDK 21, `./app/bin/orbit`,
  без аргументов — менеджер аккаунтов), `~/orbit/local` — свои данные (хранилище, `accounts.json`, конфиги, память
  бота), `~/orbit/logs` — журналы (`orbit-<акк>.log`, архив в `logs/archive/`).
- `local/accounts.json` у каждого Mac свой: корабль для Скайлаба, пара палладия, конфиг аккаунта выбираются на каждом
  отдельно. Конфиги (`local/configs/<папка>/<имя>.json`) переносятся копированием; копии до переноса —
  `local/configs.before-*`. Свои версии конфигов второго Mac не перезаписывать: сначала сравнить, недостающие —
  добавить.

## Залить сборку
1. Здесь: `./gradlew :app:distZip` (не `installDist` — старая папка установки однажды уехала вместо новой).
2. Там: программа закрыта, у каждого аккаунта в конце журнала «Сессии завершены» (иначе — ждать или просить
   пользователя; корабль в бою, закрытый на ходу, гибнет).
3. `scp app/build/distributions/orbit-0.1.0.zip` → `~/orbit-new.zip`; распаковать в новую папку; `mv ~/orbit/app
   ~/orbit/app.prev-<время>`; новую — на место `~/orbit/app`; zip → `orbit-new.zip.bak-<время>`.
4. Проверить, что в jar есть свежая правка (`unzip -p … | strings | grep …`), затем `open ~/orbit/start.command`.
   Аккаунты запускает пользователь.
