# Прокачка аккаунта с нуля до Прометеев

Цель: бот сам, без участия пользователя, ведёт новый аккаунт от 1-го уровня до полного набора лазеров «Прометей».
Черновик v1 (2026-11-16) — пользователь правит по пунктам. Факты цен — `docs/recon/SHOP-AUCTION.md`; рецепт и темп — журнал
аккаунта (ниже). Аккаунт для прокачки — int1, в хранилище «7».

## Правила

- **Не ломать то, что уже работает.** Прокачка только выбирает конфиг и тратит деньги; бой, сбор, квесты, безопасность, палладий,
  Скайлаб, обогащение — существующие модули без изменений их логики. Новое — отдельными классами рядом.
- Денег на старте нет: сначала всё за кредиты, уридий копится. **Первая покупка за уридий — двигатели G3N-7900 (2 000 уридия за штуку)**
  (пользователь 2026-11-16).
- Каждая трата — в журнал: что, за сколько, зачем, какой шаг плана. Резерв кредитов и уридия не трогается (ремонт, патроны).
- Сначала «советчик»: бот пишет, что купил бы, ничего не покупая; покупки включаются по шагам, когда пользователь согласен.

## Конфиги прокачки — папка «Прокачка»

Как «Default»: встроенные в программу, закрыты для правки (можно сделать копию). Стратег сам переключает конфиг аккаунта
на нужный этап. Набор (черновик):

| Конфиг | Для чего |
|---|---|
| Старт x-1 | стартовые миссии, Streuner/Lordakia, бонусные ящики, продажа руды |
| Фарм x-2 / x-3 | NPC по силе корабля, ящики, руда |
| Квесты | `QuestModule` с порядком типов прокачки |
| Палладий | с 12-го уровня (как действующий «Palladium») |
| Zeta | зелёные ключи, UCB-100, лог-диски |
| Blacklight Rinusk | Ринуск для Прометея и RSB-75 |

## Что нужно сделать в боте

| Часть | Что | Состояние |
|---|---|---|
| Модель аккаунта | уровень, деньги, ангары, что где стоит, дроны, Скайлаб, инвентарь — в одном снимке | нет |
| Каталог магазина | все товары с ценой и валютой, слоты кораблей — со страниц магазина | разведано |
| Покупка в магазине | корабли, лазеры, генераторы, дроны, механизмы питомца (`ajax/shop.php`, как патроны) | есть для патронов и бустеров |
| Аукцион | читать лоты, ставить в конце часа в пределах бюджета, итог в журнал | нет |
| Ангары | выбрать ангар, купить корабль (новый ангар) | выбор есть (`Hangars`) |
| Оснащение | разложить снаряжение по слотам корабля и дронов в конфигах 1 и 2 по плану (`inventory.php move`) | основа есть |
| Конфиги «Прокачка» | встроенная закрытая папка, как «Default» | нет |
| Стратег | этап плана → конфиг аккаунта + список покупок; сначала советчик | нет |
| Скайлаб | очередь улучшений модулей | нет |

Порядок работ: каталог и аукцион (чтение) → модель аккаунта → оснащение → покупки → папка «Прокачка» → стратег-советчик →
Скайлаб → стратег с покупками.
