# План работ

Статусы: `[ ]` не начато, `[~]` в работе, `[x]` готово и подтверждено пользователем.
После каждого этапа — остановка, демонстрация, подтверждение.

Зафиксированные решения:
- Запуск где угодно: Windows VPS (24/7, headless), обычный Windows-ПК, Мак. GUI и headless —
  равноправные режимы на обеих ОС; оба проверяются на Windows и на маке.
- Сервер тестов — GE1, отдельный запасной аккаунт, без 2FA.
- До 5 аккаунтов в одном процессе, у каждого необязательный прокси (SOCKS5/HTTP).
- Интерфейс, логи, README — на русском. Код и комментарии — на английском.
- Только для личного использования. Из DarkBot берём факты и логику, код целиком не копируем.
- Трафик снимаем с официального `DarkOrbit Client.app`, по возможности без правки swf.
- Код и бинарники AstraBot не используем. `reference/astra-config.json` — только справочник опций.
- .dmg без подписи.

      *Сделано (2026-11-10):* свой коннектор SOCKS5 (RFC 1928/1929, имя хоста разрешает прокси) и HTTP
      CONNECT (Basic); тип без схемы определяется сам. Сайт и картинки мини-карты идут через локального
