# План работ

Статусы: `[ ]` не начато, `[~]` в работе, `[x]` готово и подтверждено пользователем.
После каждого этапа — остановка, демонстрация, подтверждение.

Зафиксированные решения:
- Запуск где угодно: Windows VPS (24/7, headless), обычный Windows-ПК, Мак. GUI и headless —
  равноправные режимы на обеих ОС; оба проверяются на Windows и на маке.
- Сервер тестов — GE1, отдельный запасной аккаунт, без 2FA.
- До 5 аккаунтов в одном процессе, у каждого необязательный прокси (SOCKS5/HTTP).
- Интерфейс, логи, README — на русском. Код и комментарии — на английском.
- Только для личного использования. Из DarkBot берём факты и логику, код целиком не копируем.
- Трафик снимаем с официального `DarkOrbit Client.app`, по возможности без правки swf.
- Код и бинарники AstraBot не используем. `reference/astra-config.json` — только справочник опций.
- .dmg без подписи.

      *Сделано (2026-11-10):* свой коннектор SOCKS5 (RFC 1928/1929, имя хоста разрешает прокси) и HTTP
      CONNECT (Basic); тип без схемы определяется сам. Сайт и картинки мини-карты идут через локального
      посредника на 127.0.0.1, у каждого аккаунта свой (встроенный SOCKS в Java сам разрешает имя — утечка
      DNS; логин SOCKS в Java глобальный; Basic для туннелей в Java выключен). Проверка перед каждым входом:
      нет прокси — нет входа, напрямую бот не подключается. `vault set-proxy`, `orbit proxy-check`, прокси и

      принимали любой CONNECT и молчали; сквозь проходили единицы (10–20 с задержки, policy GE1 отвечает).

        (вошли с другого места — клиент отключается и пишет «doubleloggedin»), `A|STD|<текст>` (строка сервера
        простым текстом, не ключ словаря клиента; в записях за много часов ни одной — так пишет человек). Соединение
        закрывается без переподключения, расписание не повторяет вход, в журнале «Признак беды: …», в окне
        менеджера всплывает предупреждение со звуком. `ERR|1` (вход не удался) — как раньше, повтор с новым входом;
      - [ ] посмотреть вживую, что приходит при кике и от администрации (сниффер: ни одного такого случая);
      - [ ] чат (сообщения администраторов и модераторов — `DOChatUserVO.TYPE_ADMIN`) и почта
        (`UserMessageNewCommand`) не читаются: бот не подключается к чату.
- [ ] 5в.8 (пользователь) Купить 2 статических ISP-прокси SOCKS5 (выделенные, безлимит, страна, из которой обычно
      играешь; ~2–3 $ за IP в месяц), вписать main и second, проверить кнопкой «Проверить».
