# План работ

Статусы: `[ ]` не начато, `[~]` в работе, `[x]` готово и подтверждено пользователем.
После каждого этапа — остановка, демонстрация, подтверждение.

Зафиксированные решения:
- Запуск где угодно: Windows VPS (24/7, headless), обычный Windows-ПК, Мак. GUI и headless —
  равноправные режимы на обеих ОС; оба проверяются на Windows и на маке.
- Сервер тестов — GE1, отдельный запасной аккаунт, без 2FA.
- До 5 аккаунтов в одном процессе, у каждого необязательный прокси (SOCKS5/HTTP).
- Интерфейс, логи, README — на русском. Код и комментарии — на английском.
- Только для личного использования. Из DarkBot берём факты и логику, код целиком не копируем.
- Трафик снимаем с официального `DarkOrbit Client.app`, по возможности без правки swf.
- Код и бинарники AstraBot не используем. `reference/astra-config.json` — только справочник опций.
- .dmg без подписи.

- [~] 3.4 `net`: подключение, рукопожатие, вход на карту, keep-alive, переподключение с паузами.
- [~] 3.5 `humanize` (основа): последовательность и тайминги пакетов входа как у клиента — сверка с записью.
- [~] 3.6 `world`: герой, корабли, NPC, ящики, руда, порталы, станции, пет, группа, карта, зоны.
      *Сделано:* корабли/NPC/питомцы с движением, герой (сверен с клиентом: медиана 7 ед.), ящики, руда,
      порталы, станции, зоны, предметы и боеприпасы, трюм, конфигурация, ключи, «цель занята».
      *Проверено на записях:* урон по герою (39 попаданий, гибель). Единицы перезарядки — мс (по коду клиента).
      *Проверено вживую (сессии 2026-11-09):* группа (2 участника, 51 обновление), перезарядка (мс, 15 случаев).
- [~] 3.7 Данные карт (размеры, порталы, препятствия, радиация) — из клиента/DarkBot как факты.
